# DisplayPort insertion assets

These connector assets were copied from the local Isaac Lab Arena DisplayPort insertion environment so this task
does not import or reference Isaac Lab Arena at runtime. The `*_newton_sdf.usda` layers preserve the six authored
Newton SDF colliders and their validated resolution, narrow-band, padding, margin, and friction parameters.

Source: `IsaacLab-Arena/isaaclab_arena_environments/displayport_insertion_newton_assets`
